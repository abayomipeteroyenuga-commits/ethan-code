# Ethan Code v6.0 — Kids Classroom Edition

Target: code.ethandigitalacademy.org

This rebuild changes Ethan Code from a developer-looking workspace into a child-friendly online coding classroom.

## Learning method
What are we learning? → Simple meaning → Everyday example → Let me show you → Try it with me → Your turn → Quick question → What did we learn?

## Classroom stages
1. Starter — Meet Coding
2. Explorer — Make It Look Good
3. Builder — Make It Work
4. Creator — Build Real Projects

## Included
- 10 simplified course areas with 30 classroom lessons
- Technical terms introduced only after simple explanations
- Guided examples and child-friendly analogies
- Quick checks
- Simple progress and achievement badges
- Practice Corner for HTML/CSS/JavaScript
- Python taught conceptually without pretending the browser runs Python
- Four age-friendly project ideas
- Supabase-ready classroom progress table

Browser progress is a local learning preview until Ethan ID/backend integration. It is not authoritative certification data.
